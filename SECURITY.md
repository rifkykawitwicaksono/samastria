# Kebijakan Keamanan Samastria

Terima kasih telah membantu menjaga keamanan Samastria.

## Melaporkan kerentanan

- Jangan publikasikan detail kerentanan, data pelanggan, token, API key, atau bukti eksploitasi di issue atau diskusi publik.
- Jika fitur **Private vulnerability reporting** tersedia pada tab Security repository ini, gunakan fitur tersebut.
- Jika fitur tersebut belum tersedia, hubungi pemilik repository secara privat melalui profil GitHub.
- Sertakan langkah reproduksi yang aman, dampak, komponen terdampak, dan waktu pengujian. Jangan mengakses, mengubah, atau menghapus data pengguna lain.

## Batas pengujian

Pengujian hanya boleh dilakukan pada akun dan data milik sendiri atau dengan izin tertulis. Hindari pengujian beban, DDoS, brute force, malware, serta pemindaian agresif terhadap website produksi.

## Penanganan

Laporan akan ditinjau dan ditindaklanjuti sesuai tingkat risiko serta kemampuan pemeliharaan proyek. Mohon beri waktu untuk verifikasi dan perbaikan sebelum mengungkapkan detail kepada publik.

## Catatan

Kebijakan ini bukan jaminan bahwa aplikasi bebas dari kerentanan. Keamanan website juga bergantung pada konfigurasi hosting/DNS/CDN, Supabase (termasuk RLS dan Edge Functions), pengelolaan rahasia, serta konfigurasi akun GitHub.
